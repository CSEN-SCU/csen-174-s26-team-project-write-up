Sign in (web)

Auth. POST /coach needs a Firebase ID token unless app-api is started with APP_ENV=dev and APP_AUTH_BYPASS=1 in your .env (then the extension sends X-Debug-User). If you see missing_token, add that bypass for local dev or use Sign in (web) and keep a token.

MCP (experimental). Docs text is loaded by coaching-api using GOOGLE_DOCS_ACCESS_TOKEN or GOOGLE_DOCS_MCP_BRIDGE_URL. A sample HTTP bridge is prototypes/ishika/server (POST /api/mcp/call on that server), not on the main app-api at port 5050.
